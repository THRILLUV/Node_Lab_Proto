# 배포본 HTML 목업

파일 하나: [`nodelab-deploy-mock.html`](nodelab-deploy-mock.html)

브라우저에서 열면 됩니다. 서버·키·구글 로그인 없음.

## 전달할 것

이 HTML만 보내면 됩니다. 화면 순서:

1. 랜딩 → **로그인** 또는 **바로 시작하기**(게스트, 동의 없음)
2. **Google로 계속하기** → 약관 동의
3. 별명·연령대
4. 온보딩 5선택 (레벨테스트 아님)
5. 회원 홈

위쪽 검은 바로 화면을 바로 건너뛸 수 있습니다.

## 그대로 옮겨야 하는 것

- 카피, 체크 3개 + 만 14세, 국외이전은 별도 체크 없음
- 필수 미동의 / 만 14세 미만 → 가입 안 함, 랜딩
- 소셜 세션만으로는 회원 아님
- 기존 공식 `app/onboarding` 덮어쓰지 말 것. 이 온보딩은 다른 화면

## 없는 것

PDF 분할, OCR, 실제 OAuth, DB. 그건 목업이 아닙니다.

다시 뽑을 때: 저장소 루트에서 `node scripts/export-deploy-mock.mjs`
