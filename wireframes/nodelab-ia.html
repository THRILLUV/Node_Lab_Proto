NodeLab 서비스 정보 구조도 (IA)

수업 교안(유저 플로우 → IA → 화면설계서) 체계에 맞춰 핵심 경험을 한눈에 파악할 수 있도록 정돈한 구조도

⚡ 핵심 사용자 흐름 (4-Step Loop)

PDF 인풋 → 5대 선택지 → 아키네이터 드릴다운 → 완풀
Step 01

원본 업로드 & 선파싱

수능 PDF나 문제집 사진을 올리면 5초 내에 1번 문제를 크롭해 1번 탭을 즉시 오픈 (뒷번호 비동기 준비)

Step 02 (핵심)

1문항 5대 선택지 대화

정답을 쏟지 않고 ①채점 ②개념 ③손풀이 ④응용 ⑤요청 중 학생이 원하는 방식으로 수업 시작

Step 03 (차별점)

아키네이터식 드릴다운

개념 확인 질문 오답 시, 막힌 원인 후보를 1질문으로 좁히고 1칸만 해결한 뒤 다시 원문항으로 즉시 복귀

Step 04

검증된 응용문제 완풀

DeepSeek 3단계 검산(Audit)을 통과한 수치 변형 문제로 그 유형을 스스로 맞힐 때까지 훈련

2. 1문항 과외 교실

Web Classroom (Core)
Screen W-2

상단 고정 문제 헤더

스크롤 독립
  • 1~30번 진행 탭: 완료 ✓ / 학습중 ● / 대기
  • 수능 3번 크롭 원본: 배점/단원 태그 + KaTeX 수식
  • 스플릿 리사이저: 드래그 높이 조절 (168~520px)

과외 대화 스트림

5대 선택지
  • ① 빠른 채점: 정답 번호 입력 시 정오 즉시 반환
  • ② 개념 브리핑 & 확인 질문 (Sonnet 비유 설명)
    • ⚠️ 아키네이터 드릴다운 (오답 시 실패 분기)
    원인 후보를 반으로 가르는 1질문 → 1칸 해결 후 원문항 복귀
  • ③ 손풀이 첨삭 (모바일 카메라 연동)
  • ④ 파생 응용문제 (DeepSeek 3단계 검산 완풀)
  • ⑤ 기타 직접 요청 (자유 질의응답)

우측 서랍 패널

보조 도구
  • 문항 목록 (1~30): 클릭 시 상단 고정 문제 즉시 전환
  • 사이드 채팅: 맥락 오염 없는 독립 공식/팁 질문
  • 실전 모의고사 생성: 정답 셔플 / 30문항 완전 변형
