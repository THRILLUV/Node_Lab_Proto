## 내일(9/3) 회의에서 확정돼야 착수하는 것 (건드리지 마라)
- 설문 스킵 최종 범위, 랜딩 도입 여부, 응용문제 포함, 구독별 문제 수/금액, 배지 디자인, 게임화(경험치·캐릭터).

---

### Task 1: 온보딩 설문 개편 (필수 3 + 스킵)

**Files:** `lib/core/onboarding.mjs`, `index.html`, `tests/ia-onboarding.test.mjs`

- 필수: `target_band`(목표 등급) · `current_band`(현재 등급) · `grade`(학년: 고1/고2/고3/N수·검정고시/기타) — 회의 00:04:31.
- 선택(스킵 가능): 기존 `initial_pain_point`, `tutor_mode`. `exam_track` 유지.
- 카드형 UI 유지. 선택 항목에 `건너뛰기`.
- `onboardingProfilePatch`에 `current_band`, `grade` 추가 — `nl_profiles` 컬럼 필요 시 `nl_*` 마이그레이션만.
- 등급 낙인 방지: 질문 카피는 해요체, 결과 화면에서 등급 숫자 재노출 금지 (Task 3).
- 이벤트: `onboarding_complete` payload에 필수 3종 포함, 스킵 여부 `skipped` 배열 (ADR-024 틀).

### Task 2: 레벨테스트 미니 세트 (앱 제공, 스킵 가능)

**Files:** `lib/core/onboarding.mjs`(또는 신규 `lib/core/leveltest.mjs`), `index.html`, tests

- 설문 뒤 3~5문항 레벨테스트 — **앱이 문제 제공** (회의 확정). 문항은 데모 뱅크(`questions.json`/`items/`) 5지선다 재사용. 새 API 함수 금지 (12함수 캡).
- 첫 화면에 `건너뛰고 시작하기` — 스킵하면 바로 첫 문제 시작 (이탈 방지, 회의 00:21:41).
- 결과는 로컬 채점만. CAT 코드·등급 숫자 학생 화면 비노출 (ADR-021).
- 게스트에게는 보이지 않음 (첫 Google 가입 후 흐름 유지).

### Task 3: 완료 보상 + 성장 배지 카피

**Files:** `index.html`, `lib/core/onboarding.mjs`, tests

- 레벨테스트 완료 시: 보상 카피 `기출 세트 이용권을 하나 드렸어요` + 배지 스타일 결과 (`탄탄한 출발` 류 성장 카피, 등급 라벨 없음 — 회의 00:25:53).
- 실물 이용권/횟수 지급은 **하지 않는다** (BM 미확정). 카피 + `leveltest_complete` 이벤트만.
- 스킵한 사용자는 보상 없음, 문구로 안내.

### Task 4: 「AI 풀이 보기」 비교 뷰

**Files:** `index.html`, `lib/core/solve.mjs`, tests

- 채점/첨삭 뒤 버튼 「AI 풀이와 비교」 — AI 풀이 단계를 순서대로 보여주고 사용자의 손풀이(있으면)와 나란히 (회의 00:29:08).
- 기존 `/api/hint`·힌트 파이프 재사용. 새 함수 금지. 게스트는 기존 한도 안에서만.
- 정답 선공개 금지 원칙 유지: 채점 이후에만 노출.

### Task 5: 응답 시간 계측

**Files:** `index.html`(track 지점), tests

- `split_ms`·`ocr_ms`·`hint_ms` 등 단계 소요를 dataLayer 이벤트로 기록 (ADR-024 이벤트 틀, 학생 화면 비노출).
- UI 단계 축소는 데이터 보고 팀이 결정 — 이번엔 계측만.

### Task 6: 오답 다시 풀기 카드

**Files:** `index.html`, `lib/core/persist.mjs`, tests

- 회원 재방문 시 홈에 「지난 오답 N개 다시 풀기」 카드 (로컬/`nl_attempts` 읽기, 있을 때만). 푸시/알림톡 없음.
- 게스트는 대상 아님 (기록 미저장 원칙).

### Task 7 (보류): 랜딩 카피 초안
