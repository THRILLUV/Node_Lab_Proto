# NodeLab 디자인

팀원이 프로토를 같은 룩으로 만들 때 쓰는 핸드오프다.  
피그마·별도 디자인 시스템 문서는 없다. **지금 돌아가는 웹 프로토 HTML이 기준**이다.

- 클릭 프로토: `wireframes/nodelab-proto.html`
- 정적 와이어: `wireframes/nodelab-wireframe.html` (프로토가 여기 CSS를 그대로 가져옴)
- 운영 콘솔: `wireframes/nodelab-admin.html` (같은 토큰, 레일만 다크)
- 아이폰 목업: `wireframes/nodelab-app-wireframe.html` (웹과 다른 다크 카메라 UI. 웹 프로토에 섞지 말 것)

이 문서는 새 룩을 제안하지 않는다. 위 파일에 박힌 값만 적는다.

## 토큰 (그대로 복붙)

학생 웹 프로토 `:root`:

```css
:root {
  --surface-primary: #f5f5f7;
  --surface-secondary: rgba(255,255,255,.62);
  --surface-elevated: rgba(255,255,255,.86);
  --surface-paper: #fff;
  --text-primary: #1d1d1f;
  --text-secondary: #6e6e73;
  --text-tertiary: #86868b;
  --border-default: rgba(29,29,31,.08);
  --border-subtle: rgba(29,29,31,.05);
  --accent-primary: #0071e3;
  --accent-tutor: #0f9d8a;
  --glow-orb: rgba(0,113,227,.14);
  --ok: #0f9d8a;
  --ng: #c93434;
  --ease: cubic-bezier(.32,.72,0,1);
  --font: "Pretendard Variable", Pretendard, -apple-system, BlinkMacSystemFont, "SF Pro Text", "Apple SD Gothic Neo", sans-serif;
  --display: "Plus Jakarta Sans", "Pretendard Variable", sans-serif;
}
```

운영 콘솔만 배경을 `#f3f4f6`로 두고, 경고 앰버 `--warn: #c47b17`을 추가한다. 그 외 토큰은 같다.

### 역할

| 토큰 | 쓰는 곳 |
| --- | --- |
| `--surface-primary` | 페이지 바닥. 애플 라이트 그레이 |
| `--surface-secondary` / `--surface-elevated` | 글래스 패널, 입력 상자 |
| `--surface-paper` | 문제판(흰 종이) |
| `--text-primary` | 제목, 본문, 검정 CTA |
| `--text-secondary` | 설명, 보조 버튼 글자 |
| `--text-tertiary` | 캡션, kicker, placeholder |
| `--accent-primary` | 링크/포커스/선택/진행 하이라이트. **메인 CTA 배경으로 쓰지 않음** |
| `--accent-tutor` | 브랜드 닷, 학습 단계, 성공, eyebrow |
| `--ng` | 오답, 위험, 정지 |
| `--warn` | 운영 콘솔 대기 상태만 |

## 타이포

- 본문: `--font`, `letter-spacing: -.02em`
- 로고·히어로·가격·큰 숫자: `--display`
- 본문 기본 13–16px. 캡션 10–11px. 홈 인사 34px / 600 / `-0.035em`
- 랜딩 히어로: `clamp(46px, 6vw, 82px)`, `line-height: .98`, `-0.06em`
- kicker / overline: 10–11px, weight 650–800, `letter-spacing: .12em`~`.14em`, uppercase, 색은 틸 또는 `--text-tertiary`

한글 UI 카피는 짧고 낮게. 영문 마케팅 카피를 히어로에 올리지 않는다.

## 레이아웃

### 공개 화면 (랜딩 / 로그인 / 요금)

- 바닥 오브 위에 카드: 폭 `min(1120px, 100%)`, 모서리 32px, 반투명 흰 글래스
- 히어로: 왼쪽 카피 + 오른쪽 스텝 카드 (900px 이하에서 카드 숨김)

### 로그인 후 앱 (핵심)

```
[ 280px 레일 ]  12px 갭  [ 메인 ]
```

- 바깥 패딩 14px, 높이 `100dvb`, `overflow: hidden`
- 세션 중에는 메인 안에 **위 문제판 / 아래 대화** + 오른쪽 **280px 문항 서랍**
- PDF 분할 중: 메인 `1fr` + 오른쪽 로그 카드 300px

모바일(≤900px): 레일·서랍은 오버레이 드로어. 레일 폭 `min(304px, 86vw)`.

### 운영 콘솔

```
[ 240px 다크 레일 #1d1d1f ]  [ 본문 #f3f4f6 ]
```

학생 왼쪽 메뉴에 운영 콘솔 항목을 넣지 않는다.

---

## 재질 · 모서리 · 그림자

- **글래스 셸**: 바깥 28px / 안쪽 22px. `backdrop-filter: blur(28px) saturate(1.4)`
- **알약**: 버튼·칩·탭·토스트 `border-radius: 999px`
- **카드**: 20–22px. 모달 22–24px. 입력 12–14px
- **아바타 / 아이콘 원**: 50%
- 얕은 그림자: `0 18px 40px rgba(15,23,42,.05)` ~ `.06`
- 랜딩/모달만 더 깊게: `0 24px 70px` / `0 28px 80px`
- 배경 오브: 왼쪽 파란 glow, 오른쪽 틸. 운영 콘솔에서는 끈다

---

## 모션

- 기본 이징: `cubic-bezier(.32, .72, 0, 1)`
- 화면 등장: 420–480ms, `translateY(10px)` → 제자리
- 호버: `translateY(-1px)`, 180ms
- `prefers-reduced-motion: reduce`면 애니메이션/트랜지션 전부 끈다
- 새 화면마다 다른 이징을 만들지 않는다

## 컴포넌트

### 버튼

| 종류 | 모양 |
| --- | --- |
| Primary / Send | `#1d1d1f` 배경, 흰 글자, 알약. 랜딩은 `padding: 12px 20px`, weight 700 |
| Secondary | 흰 배경 + `--border-default` |
| Ghost | 연한 `#f5f5f7` 알약, 12px |
| Link | 투명, `--text-secondary` |
| Round (첨부/전송) | 34×34 원. 전송만 검정 필 |
| Danger (운영) | `rgba(201,52,52,.10)` + `#c93434` |
| OK (운영) | `rgba(15,157,138,.12)` + 틸 |

**파란 필 버튼을 메인 CTA로 쓰지 않는다.** 블루는 선택·포커스·진행이다.

### 입력

- 일반 필드: 흰 배경, 테두리 `--border-default`, radius 13px, padding 12px 13px
- 포커스: 테두리 `rgba(0,113,227,.45)`, 링 `0 0 0 3px rgba(0,113,227,.08)`
- 홈 컴포저: 테두리 없는 투명 textarea, 상자만 글래스 22px
- 세션 하단 컴포저: 알약(모바일은 22px)

### 칩 · 배지

- 홈 제안 칩: 흰 70% + 보더, 알약, 13px, `--text-secondary`
- 문제 배지: `#0071e3` 필, 흰 글자, 11px / 700
- 개념 칩: 틸 10% 배경 + 틸 글자
- 상태 칩: 틸 10% (학습중/활성)
- 운영: Free=파란 틴트, Pro=검정 필, 정지=빨강 틴트, 대기=앰버 틴트

### 로고

Plus Jakarta 15px / 700 + 틸 닷 8px (`box-shadow: 0 0 10px rgba(15,157,138,.55)`). 워드마크는 `NodeLab`.

### 레일

- 새 세션: 알약, elevated 글래스, 13px / 600
- 메뉴: 13px, radius 12px, 기본 `--text-secondary`
- 활성 세션: `rgba(0,113,227,.10)` + 파란 글자 / 600
- 푸터 아바타: 28px, `#e8e8ed`

### 대화

- AI 버블: elevated 글래스, radius 20px, 14px / 1.55
- 유저 버블: `#1d1d1f` 필, 최대 너비 80%
- AI 아바타: 틸 원 / 유저 아바타: 검정 원
- 선택지 `.dec`: 흰 카드 14px. 호버 시 파란 테두리 + 파란 글자

### 문제판

- 흰 종이, radius 22px, 기본 높이 268px (188–520, 세로 리사이즈)
- **원본 문항은 `items/q01–q30.png` 크롭만.** 원문에 KaTeX·재조판 금지
- KaTeX는 생성된 변형 문항에만

### 피드백

- 토스트: 하단 중앙, 검정 알약, 흰 글자
- 모달: 딤 `rgba(15,23,42,.28)` + blur 8px, 흰 카드 24px
- 진행 바: 6–8px 알약, 파랑→틸 그라데이션
- 정답/오답 verdict: 틸 또는 빨강 틴트 알약
- 스켈레톤: `#ececf1` ↔ `#f7f7f9` shimmer

### 운영 테이블

- 흰 패널 22px, 행 호버 `rgba(0,113,227,.04)`
- 숫자 카드: 흰 20px, 숫자는 display 32px / 750

## 구현 순서 (다른 프로토를 만들 때)

1. 위 `:root`와 폰트 CDN을 먼저 넣는다.
2. 바닥색 + 오브 + 글래스 셸을 깐다.
3. 레일 280 / 메인 1fr 그리드를 짠다.
4. 버튼은 검정 필 / 고스트 / 칩만 쓰고, 블루는 상태값에만 쓴다.
5. 화면을 새로 그릴 때도 `nodelab-proto.html`의 같은 클래스 패턴을 복사한다. 토큰만 맞추고 레이아웃을 바꾸지 않는다.

값이 문서와 HTML이 다르면 **HTML을 따른다.**
