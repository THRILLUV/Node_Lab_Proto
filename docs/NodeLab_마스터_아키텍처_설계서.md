## 1. 프로덕트 핵심 정의 및 차별화 (Core Thesis)

* **서비스 정의**: 수능/검정고시/편입 수학 자습 중 막힌 문제의 논리 결손(Logic Gap)을 실시간으로 감사(Audit)하고, 숫자가 바뀐 변형 문제까지 스스로 완풀하게 만드는 **교육 논리 감사 에이전트 서비스**.
* **3대 핵심 가치**:
  1. **AX-Natural Input**: 타이핑 없이 PDF 분할 / 책상 위 노트 카메라 비춤 / 태블릿 펜슬 필기로 즉시 연결.
  2. **Audit Integrity (수학적 무결성)**: 단순 LLM 추론이 아닌 `SymPy` 기호수학 엔진 기반 3단계 검산 가드레일.
  3. **Pacemaker Tutoring (비-스포일러 튜터링)**: 정답을 일방적으로 쏟아내지 않고 5대 선택지와 1-질문 힌트로 유저 스스로 완풀 유도.

## 2. 확정된 7대 아키텍처 결정 기록 (ADR Summary)

| ADR 번호 | 주제 | 확정된 결정 내용 |
|---|---|---|
| **ADR-001** | 인터랙션 순서 | **5대 선택지 우선 ➔ 손풀이 요청**: 아는 문제를 빠르게 넘기는 유저의 피로도 제거 |
| **ADR-002** | 피드백 전략 | **오류 유형별 적응형 분기**: 계산 실수(CAT_4)는 1초 원샷 카드, 개념 결손(CAT_2/3)은 1-질문 소크라테스 대화 |
| **ADR-003** | 변형문제 검증 | **3단계 파이프라인**: 생성 ➔ SymPy 결정론적 검산 ➔ KaTeX 렌더링 (환각 100% 방어) |
| **ADR-004** | 멀티 디바이스 | **웹 표준 컴패니언**: 모바일 웹 후면 카메라 `<video>` + CSS Glass 오버레이 + WebSocket 실시간 동기화 |
| **ADR-005** | 비용 및 모델 라우팅 | **비대칭 Generator-Verifier**: 초저가 DeepSeek V4 Flash(생성) + SymPy/Gemini(블라인드 검증) ➔ 건당 1원 미만 |
| **ADR-006** | 초기 경험 (Aha) | **온보딩 직후 샘플 자동 로드**: Q1 트랙의 1번 문제와 5선택지가 즉시 세팅되어 10초 만에 핵심 가치 체감 |
| **ADR-007** | 완풀 및 지표 갱신 | **담백한 성취 축하 & 백단 누적**: 초록 탭 전환 + 담백한 토스톤 축하 + Master 지표 백단 자동 상향 |

## 3. 전체 시스템 데이터 파이프라인

```
[ 1. 온보딩 (5지선다) ] ➔ exam_track, target_band, initial_pain_point, volume, tutor_mode
         │
         ▼
[ 2. 학습 세션 (PC/태블릿) ] ◀── WebSocket ──▶ [ 모바일 웹 카메라 컴패니언 ]
  - 상단: 원본 크롭 문제판 (고정)               - 후면 카메라 뷰파인더
  - 중앙: 5대 선택지 대화창                      - 실시간 세션 연동 오버레이
  - 우측: 문항 1~30 서랍 / 펜슬 캔버스          - Hold-to-Talk 붉은 버튼
         │
         ▼ [ ③ 손풀이 첨삭 / 필기 제출 ]
[ 3. 백엔드 검산 엔진 (stem-tutor-agent) ]
  ① OCR / 수식 정규화 (Gemini 3.7 Flash)
  ② 단계별 동치 검산 (SymPy 로컬 CPU)
  ③ CAT 1~4 결손 진단 & 1-질문 힌트 생성  ← 구현 후순위, 적용 범위는 ADR-021
         │
         ▼ [ ④ 파생 응용문제 요청 ]
[ 4. 비대칭 변형 문제 엔진 ]
  ① 생성자: DeepSeek V4 Flash (수치/해설 생성)
  ② 검증자: SymPy + Gemini 블라인드 재풀이
         │
         ▼ [ 완풀 완료 ]
[ 5. Master 지표 갱신 & Pro 구독 페이월 ]
  - concept_mastery_score 상향 누적
  - 무료 일 3회 초과 시 월 9,900원 구독 안내
```

## 4. 5대 R&R 직무별 구현 범위

* **회원 및 유입 PM (박태희)**: 인트로, 구글 소셜 로그인, 마이페이지, 온보딩 5문항 인터페이스, 기기별 반응형 레이아웃.
* **AI 코어 경험 PM (김홍)**: 5대 선택지 대화 SOP, CAT 1~4 진단 프롬프트, `stem-tutor-agent` 연동, Master 지표 누적 로직.
* **과금 및 수익화 PM (변희웅)**: 무료 일 3회 / Pro 월 9,900원 요금제, 페이월 모달, 결제 실패/환불 정책, 유닛 에코노믹스 시뮬레이션.
* **그로스 및 마케팅 PM (손소연)**: D-Day 알림톡(수능/모평/편입), 루틴형 리텐션 푸시 분기, 초기 게릴라 모객 시나리오.
* **운영 및 백오피스 PM (장명희)**: 관리자 대시보드(회원 목록/상세, 정지/크레딧 지급, 토큰 원가 모니터링, AI 예외 대응 큐).
