## 3. 크레딧 (빚 좋은 개살구)

횟수가 진짜 한도. 크레딧은 “이만큼 받았다” 연출. 라이트는 횟수에 먼저 걸림.

| | 월 지급 |
|---|---|
| 라이트 | **3만** |
| 베이직 | **10만** |
| 헤비 | **50만** (가격 3배, 크레딧 5배 느낌) |

남는 크레딧 사용처(선물, 쿠폰, 소셜)는 **나중에.** 지금은 안 만듦.

대화 턴도 크레딧에서 깎을 예정. 한국어가 영어보다 토큰을 더 먹음 → 아래 조사.

## 4. 한국어 vs 영어 토큰 (조사)

같은 뜻이면 한국어가 영어보다 토큰이 **약 1.4배**(최신 토크나이저) ~ **2.3배**(구형) 더 나간다. 한글 한 글자가 토큰 1개에 가깝고, 영어 단어는 1토큰인 경우가 많다.

- 측정 예: 영어 12토큰짜리 문장 ≈ 한국어 20토큰 (o200k)
- 블로그 285편 대량 측정: 한국어/영어 **1.38배** (o200k), cl100k에선 **1.82배**
- 문장 번역 평균으로 한국어 **2.36배**라는 연구도 있음 (토크나이저마다 다름)

실무: 크레딧은 **글자가 아니라 행동(턴/손풀이/응용)** 으로 깎아라. 한글 토큰세는 우리 원가 장부에만 반영. Gemini `usage_metadata`로 나중에 실측.

출처 메모: jangwook.net 2026-06 측정(1.38x), tonybaloney CJK 평균 한국어 2.36x.

## 5. 크레딧 차감 초안 (횟수가 먼저 닳게)

| 행동 | 크레딧 |
|---|---|
| 손풀이 OCR 1회 | 100 |
| 응용 1회 | 30 |
| 대화 1턴 (유저 메시지+답) | 15 |
| 업로드 1문항 인식 | 5 |

한도 풀로 써도 크레딧이 횟수보다 늦게 바닥:
- 라이트 3만: 손풀이 150×100 + 응용 150×30 = 19,500. 대화 여유.
- 베이직 10만: 손풀이 600×100 + 응용 900×30 = 87,000.
- 헤비 50만: 1,000×100 + 1,000×30 = 130,000. 많이 남음 = 의도된 개살구.
