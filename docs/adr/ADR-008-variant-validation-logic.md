# ADR-008: 변형 응용문제 생성 모델 선정 및 5단계 무결성 검증 로직 명세

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
변형 응용문제를 실시간으로 무제한 생성할 때, 생성된 문제가 실제로 풀 수 있는 문제인지(Well-posed), 수식 오류나 모순이 없는지, 정답이 깔끔한 수능/시험 규격에 맞는지, 그리고 원본 문항의 핵심 개념을 그대로 유지하고 있는지를 기계적으로 판정하는 엄밀한 검증 체계가 필요함.

---

## 1. 모델 역할 분담 (Model Allocation)

| 역할 | 담당 모델 / 엔진 | 주요 임무 및 특징 | 비용 |
|---|---|---|---|
| **생성자 (Generator)** | **DeepSeek V4 Flash** (또는 Gemini 3.7 Flash) | 원본 문제의 수치와 미지수를 변형하여 문제 지문, 5지선다 보기, 풀이 단계, 정답을 2초 내 생성 | 건당 약 0.3원 |
| **결정론적 계산기 (Solver)** | **SymPy** (로컬 Python 엔진) | 기호수학 연산으로 방정식의 해, 분모 0 여부, 도함수/적분값, 판별식을 수학적으로 완벽 검산 | **0원** (로컬 CPU) |
| **블라인드 감사자 (Verifier)** | **Gemini 3.7 Flash** (고지능 가드레일) | 생성자의 정답을 보지 않은 채 지문만 보고 독립적으로 재풀이하여 정답 및 문항 성립 여부 최종 일치 대조 | 건당 약 0.8원 |

---

## 2. 변형 문제 검증 5단계 게이트 (Validation Gate)

생성된 변형 문제는 아래 5개 게이트를 **모두 통과(Pass)**해야만 학생 화면에 출제됩니다.

```
[ 생성자: 변형 문제 초안 생성 ]
       │
       ▼
┌─────────────────────────────────────────────────────────────┐
│ [Gate 1] 수식 구문 검증 (Syntax Gate)                       │ ➔ 실패 시: 재시도
│  - LaTeX 문법 오류 없는가?                                  │
│  - 5개 선택지가 모두 서로 다른 값인가? (보기 중복 방지)      │
├─────────────────────────────────────────────────────────────┤
│ [Gate 2] 수학적 성립성 검증 (SymPy Math Engine)             │ ➔ 실패 시: 재시도
│  - 분모가 0이 되는 특이점이 존재하는가? (f(x)/0 차단)      │
│  - 방정식/부등식의 해가 실제로 존재하는가? (해가 없는 모순) │
│  - 로그의 밑과 진수 조건(x > 0, x != 1)을 만족하는가?       │
├─────────────────────────────────────────────────────────────┤
│ [Gate 3] 교육과정 정답 규격 검증 (Curriculum Gate)          │ ➔ 실패 시: 재시도
│  - 객관식: 정답이 5개 보기 중 정확히 1개만 존재하는가?      │
│  - 주관식/단답형: 정답이 수능 규격(1~999 자연수)인가?       │
│  - 복소수나 더러운 무리수가 아닌 깔끔한 유리수/정수인가?   │
├─────────────────────────────────────────────────────────────┤
│ [Gate 4] 이중 블라인드 일치 검증 (Double-Blind Gate)         │ ➔ 실패 시: 재시도
│  - 검증자 모델이 문제만 보고 푼 정답 == 생성자의 주장 정답?  │
│  - SymPy 계산값 == LLM 검증자 풀이값 일치 여부 대조         │
├─────────────────────────────────────────────────────────────┤
│ [Gate 5] 동형성(Isomorphism) 검증 (Type Consistency)         │ ➔ 실패 시: 재시도
│  - 원본 문제의 핵심 풀이 단계(SOP)와 변형 문제 단계가 동일한가? │
│  - (예: 지수 밑 통일 ➔ 지수방정식 2차식 치환 단계 유지)   │
└─────────────────────────────────────────────────────────────┘
       │
       ▼ (모두 통과 시)
[ 학생 화면 문제판에 KaTeX로 즉시 렌더링 ]
```

## 3. 예외 및 실패 처리 (Fallback & Retry)

* **1회 실패 시**: 유저에게 로딩 인디케이터(스켈레톤)를 유지한 채, 1.5초 내에 초저가 생성자가 새로운 수치로 1회 즉시 재생성.
* **2회 연속 실패 시 (극단적 케이스)**: AI 실시간 생성을 중단하고, 사전에 무결성이 100% 검증된 정적 백업 변형 문제(`questions.json` 캐시)를 즉시 배출하여 유저 대기 시간 3초 미만 보장.

---

## 4. 기대 효과
* 수식 붕괴나 답이 없는 오류 문제 출제를 100% 원천 차단.
* 교육 논리 감사(Audit) 에이전트라는 서비스 본질에 걸맞은 학술적·기술적 무결성 확보.
* 검증 파이프라인의 80%를 로컬 SymPy(0원)로 처리하여 원가 마진 극대화.
