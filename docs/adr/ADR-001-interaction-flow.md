# ADR-001: 학습 세션 진입 시 5대 선택지 우선 인터랙션 플로우

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
NodeLab의 학습 세션에서 학생이 문제를 마주했을 때, 백엔드 검산 엔진(`stem-tutor-agent`)의 풀이 전수 검산 방식과 프론트엔드 UI의 5대 선택지(빠른 채점 / 개념 설명 / 손풀이 첨삭 / 파생 응용문제 / 직접 요청) 인터랙션 순서 간의 결합 방식을 정의할 필요가 있었음.

## 결정
**선택지 우선 ➔ 손풀이 요청 방식 (Option B) 채택**
1. 문제 진입 시 상단에 문제 원본을 고정하고, 하단 대화창에 5대 선택지 카드를 먼저 노출한다.
2. 유저가 '③ 손풀이 첨삭' 또는 풀이 검증이 수반되는 액션을 선택했을 때에만 우측 손풀이 캔버스/카메라 연동 뷰파인더를 활성화하여 입력을 받는다.
3. '① 빠른 채점'이나 '② 개념 브리핑' 등 손풀이가 불필요한 상황에서는 불필요한 필기 입력을 강제하지 않는다.

## 결과 및 기대효과
- 아는 문제를 빠르게 넘기려는 상위권 유저와 개념만 보려는 유저의 불필요한 입력 피로도 제거.
- 세션 진입 단계의 인지 부하를 줄이고, 명확한 유저 의도(Intent) 접수 후 적합한 백엔드 파이프라인만 선택적 호출(API 비용 절감).
