# ADR-016: 모바일 토크백(Hold-to-Talk) STT/TTS 음성 엔진 선정 및 비용 제로(0원) 아키텍처

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
스마트폰 컴패니언 화면에서 붉은색 버튼을 누르고 있는 동안 음성 질문을 인식(STT)하고, AI 답변을 자연스러운 음성으로 읽어주는(TTS) 기능을 구현할 때, API 호출 비용을 0원으로 통제하면서도 0.5초 이내의 초저지연(Low-Latency) 반응 속도를 달성할 수 있는 음성 엔진 스택을 선정함.

---

## 1. 확정된 STT / TTS 엔진 스택

| 구분 | MVP 기본 엔진 (확정) | 이후 후보 (상용 고도화, 지금 안 씀) |
|---|---|---|
| **STT (음성 인식)** | **웹 표준 `Web Speech API` (`webkitSpeechRecognition`)**<br>- 비용: **$0**<br>- 지연: 기기 내장 실시간 스트리밍<br>- PC 채팅바 마이크 + 모바일 토크백 동일 모듈<br>- iOS Safari / Android Chrome | **Groq `whisper-large-v3`**<br>- 시간당 $0.111<br>- MVP 이후 인식률이 모자랄 때만 재검토<br>- 출처: https://groq.com/pricing |

## 2. 왜 웹 표준 Web Speech API가 최적인가?

1. **PC 웹 & 모바일 웹 100% 동일 엔진 공유**:
   - PC 웹의 입력창 마이크 버튼(`●`)과 스마트폰 뷰파인더의 토크백 버튼이 **동일한 단일 자바스크립트 모듈**로 동작함.
   - PC 브라우저(크롬/사파리/엣지)에서도 마이크 버튼을 누르고 말하면 입력창에 실시간으로 수식/질문 텍스트가 즉시 채워짐.
2. **API 원가 0원 (비용 부담 제로)**:
   - 유저가 토크백이나 웹 마이크를 100번 눌러 질문해도 서버 API 비용이 단 1원도 발생하지 않음.
   - 유닛 에코노믹스 마진율을 85% 이상으로 방어하는 핵심 기제.
3. **네트워크 지연 0초 (즉시 인식)**:
   - 오디오 파일을 서버로 업로드하고 변환할 필요 없이, 기기 내부 OS(Neural Engine)에서 말을 끝마치는 순간 텍스트로 즉시 변환.
4. **무전기(Hold-to-Talk) 및 클릭 토글 인터랙션**:
   - 모바일: 버튼을 누를 때 `recognition.start()` ➔ 손을 뗄 때 `recognition.stop()`.
   - PC 웹: 마이크 아이콘 클릭 시 녹음 시작(붉은 펄스 효과) ➔ 말 끝나면 자동 전송 또는 입력창 자동 채움.

## 3. 음성 응답 정책 (Voice Reply Policy)

* **선택적 TTS 원칙**:
  - 학생이 **음성(토크백)으로 질문했을 때에만** AI가 3줄 요약 핵심 답변을 음성으로 함께 읽어줌.
  - 학생이 텍스트로 타이핑하거나 버튼만 눌렀을 때는 음성 없이 텍스트로만 조용히 피드백 (독서실/도서관 자습 환경 보호).
* **음성 음소거 토글**:
  - 화면 상단에 `[🔊 / 🔇]` 토글 버튼을 상시 배치하여 언제든 음성 답변을 끌 수 있도록 제어권 제공.
