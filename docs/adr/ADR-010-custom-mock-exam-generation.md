# ADR-010: 자습 완주 후 맞춤형 실전 모의고사 3대 생성 모드 및 평가 정책

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
시험지 30문항 학습을 마친 후 단순 학습 종료로 끝내지 않고, 학생이 '답 번호 암기'로 인한 착시를 방지하고 실전 감각을 극대화할 수 있는 맞춤형 실전 모의고사 생성 기능이 필요함.

---

## 1. 실전 모의고사 3대 생성 모드

유저가 학습을 마치거나 우측 서랍의 `[실전 모의고사 만들기]`를 클릭했을 때 아래 3가지 모드 중 원하는 시험지를 1초 만에 즉시 생성합니다.

```
┌─────────────────────────────────────────────────────────────┐
│  🎓 어떤 모의고사로 실전 감각을 다져볼까요?                   │
├─────────────────────────────────────────────────────────────┤
│  [모드 1] 🔀 순서·보기 셔플 모의고사                          │
│   - 문제 순서(1~30번)와 5개 선택지 순서를 무작위로 섞음        │
│   - "답 번호(3번 등)를 외워서 푸는 착시" 원천 차단            │
├─────────────────────────────────────────────────────────────┤
│  [모드 2] 📄 원본 깨끗이 다시 풀기                           │
│   - 업로드한 원본 문제와 순서 그대로 백지 상태 재도전         │
│   - 해설 없이 내 힘으로 100점 맞을 수 있는지 최종 점검       │
├─────────────────────────────────────────────────────────────┤
│  [모드 3] ⚡ 완전 변형 30제 모의고사 (AI New 30-Pack)         │
│   - 30개 문항의 유형/개념은 그대로, 숫자는 완전히 새로운 문제  │
│   - 어디서도 본 적 없는 나만의 2026 수능 실전 모의고사 완성   │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 모드별 기술 구현 및 가드레일

1. **모드 1 (셔플 모의고사)**:
   - 클라이언트단에서 순열 알고리즘(Fisher-Yates Shuffle)으로 1~30번 문항 순서와 1~5번 보기 순서를 재배치.
   - API 호출 비용 **0원** (즉시 생성).
2. **모드 2 (원본 재풀이)**:
   - 기존 세션의 오답/채점 기록만 초기화한 클린 인스턴스 생성.
   - API 호출 비용 **0원**.
3. **모드 3 (완전 변형 30제)**:
   - `ADR-005`, `ADR-008`의 비대칭 생성-검증자(DeepSeek 생성 + SymPy/Gemini 검산) 파이프라인으로 30문항 일괄 생성.
   - Pro 유저에게 제공되는 핵심 킬러 기능 (Free 유저는 10문항 미니 모의고사 제공).

---

## 3. 비즈니스 및 학습 효과

* **독보적 차별화 (학습 착시 제거)**:
  * 기존 문제집/인강은 한 번 풀면 답 번호(예: "아 3번 답 4번이었지")가 기억나서 다시 풀 때 실력 측정이 안 됨.
  * 셔플 및 완전 변형 모의고사는 '진짜 실력'만으로 풀게 강제하여 성적 향상 직결.
* **Pro 구독 결제 유인(WTP) 극대화**:
  * "내 시험지의 30문제를 숫자가 싹 바뀐 새로운 시험지로 만들어준다"는 기능은 고관여 수험생/학부모에게 가장 강력한 결제 명분이 됨.
