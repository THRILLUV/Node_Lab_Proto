# ADR-020: CAT 결손 진단 기반 실시간 학습 상태 트리거 및 3단계 시각화(학습자·리포트·관리자) 명세

## 상태
부분 확정 - 2026-09-01
- **MVP 적용 범위는 ADR-021이 SoT.** 이 문서 2절(게이지·계통도·등급 시뮬레이션·관리자 히트맵)은 2차 백로그다.
- 구현은 후순위. 백엔드에 지금 붙이지 않는다.

## 맥락
김홍 CAT v0.6을 세션 백엔드의 다음-한-수 방아쇠로 쓰기 위한 방향 문서. 학생 화면에는 CAT 코드를 내지 않는다.

---

## 1. CAT 진단이 실시간으로 발동시키는 4대 학습 트리거 (How to Trigger)

학생이 손풀이를 제출하면 AI가 0.5초 만에 CAT 코드를 확정하고, 시스템이 자동으로 다음 4가지 분기 동작을 즉시 트리거합니다.

| 진단 코드 | 결손 본질 | 시스템 자동 트리거 동작 (Immediate Action) |
|---|---|---|
| **CAT_1** (이해 병목) | 문제의 목표/조건을 놓침 | **[조건 하이라이트 트리거]**: 문제 지문에서 놓친 필수 제약 조건(예: $x>0$, 자연수 $a$)에 형광펜 펄스 효과 부여 |
| **CAT_2** (선수개념 결손) | 하위 학년 공식/성질 모름 | **[3단계 드릴다운 트리거]**: `ADR-013` 가동 ➔ 3줄 직관 요약 + 1-Step 미니 퀴즈 출제 (Depth 1~5 격차 반영) |
| **CAT_3** (수식화 오류) | 개념은 아는데 식을 못 세움 | **[핵심 관계식 가이드 트리거]**: 발문과 공식을 이어주는 징검다리 힌트 1줄 제공 |
| **CAT_4** (연산 실수) | 식은 맞았으나 부호/계산 실수 | **[1초 원샷 핀포인트 트리거]**: 틀린 줄 번호와 [틀린 식 ➔ 맞은 식] 시각 대조 카드 노출 |

## 2. 수집된 CAT 데이터 시각화 및 열람 화면 3종 (How to View)

어려운 내부 코드(`CAT_2_GEO_MS_3` 등)를 그대로 노출하지 않고, 사용자 대상별로 맞춤 변환하여 보여줍니다.

```
[ 1. 학생용: 오답노트 & 홈 ]     [ 2. 유료 실물: 심층 Audit 리포트 ]     [ 3. 운영자용: 관리자 콘솔 ]
  - 3대 역량 게이지 그래프       - 월간 성취도 진단서 (PDF 다운)         - 문항별 집단 결손율 히트맵
  - 선수개념 계통 트리 지도       - 개념 회복 궤적 & 예상 등급 상승       - 취약 단원별 유저 코호트 분석
```

### ① 학습자 화면 (오답노트 & 홈 대시보드)
* **3대 역량 게이지**:
  * `문제 해석력 (CAT_1)`: 92% (우수)
  * `개념 완성도 (CAT_2/3)`: 74% (보완 필요 - [시그마 공식])
  * `계산 정확도 (CAT_4)`: 88% (양호)
* **선수개념 계통 지도 (Knowledge Tree)**:
  * 고2 [삼각함수]에서 막힌 뿌리가 `중3 [삼각비 특수각]`이었음을 깔끔한 인포그래픽 트리로 시각화하여 내 약점의 근본 뿌리를 직관적으로 보여줌.

### ② 결제자 / 학부모용 (Pro 전용 실물 가치: 심층 Audit 진단 리포트)
* **월간/주간 AI 교육 논리 감사 보고서 (PDF)**:
  * 총 풀이 문항 수 및 완풀률
  * 최초 결손 분석: "이번 달 오답의 60%는 단순 계산이 아닌 중학 선수개념(CAT_2) 결손에서 발생했습니다."
  * 회복 궤적: "AI 튜터의 3단계 드릴다운을 통해 지수·로그 단원 숙달도가 $0.32 \rightarrow 0.85$로 수직 상승했습니다."
  * 예상 성적 변화: 2026 수능 수학 예상 등급 4등급 ➔ 2등급 상승 시뮬레이션.

### ③ 운영자 화면 (관리자 대시보드 - 장명희 R&R)
* **문항별 결손 히트맵**: 2026 수능 30문항 중 유저들이 가장 많이 틀린 문항과 지배적인 CAT 유형(예: "3번 문항은 CAT_2가 68% 집중")을 파악하여 변형 문제 풀 우선 보강.

---

## 3. 기대 효과
* 홍 님이 설계한 학술적 CAT 지표가 **제품의 실시간 동작 트리거(UI/UX)**와 **유료 구독 결제 명분(Audit 리포트)**으로 100% 완벽하게 결합됨.
