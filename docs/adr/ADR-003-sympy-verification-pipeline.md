# ADR-003: 변형 응용문제 생성 시 3단계 기호수학(SymPy) 검산 가드레일 파이프라인

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
수학 교육 서비스에서 AI가 생성한 변형 문제에 수학적 오류(분모 0, 복소수 해, 문제 조건 모순, 답 불일치 등)가 포함될 경우 서비스 신뢰도에 치명적인 타격을 입힘. Zero-Data 실시간 생성 환경에서 수학적 무결성을 보장하는 검증 체계가 필수적임.

## 결정
**3단계 생성-검산-확인 파이프라인 (Option B) 채택**

1. **1단계 (생성)**: LLM(Gemini / DeepSeek)이 원본 문제의 핵심 논리 구조를 유지하면서 수치와 조건을 변형한 문제 초안 및 표준 풀이/정답을 생성.
2. **2단계 (기호수학 검산)**: 백엔드의 `SymPy` 기호수학 엔진으로 생성된 수식의 해(Root), 도함수, 적분값, 도메인 제약 조건을 결정론적(Deterministic)으로 검증.
   - 분모가 0이 되는 특이점 필터링
   - 고등 수학 범위(실수/유리수/자연수 정답) 충족 여부 확인
3. **3단계 (렌더링 및 Fallback)**:
   - 검증 통과 시: 문제판에 KaTeX로 수식을 렌더링하여 유저에게 즉시 제공.
   - 검증 실패 시: 유저에게 에러를 노출하지 않고 백그라운드에서 1회 재생성 시도, 재실패 시 사전 검증된 안전 백업 문항 노출.

## 결과 및 기대효과
- 환각 없는 무결한 변형 문제 제공으로 '교육 논리 감사(Audit)'의 기술적 실체 입증.
- 사전 문제은행 구축 비용 없이 무한대의 개인 맞춤형 변형 문제 파이프라인 확보.
