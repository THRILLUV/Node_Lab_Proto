# ADR-013: 3단계 미니멀 개념 드릴다운(직관 요약 ➔ 1문항 확인 ➔ 원문항 복귀) 튜터링 프레임워크

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
기존 인강이나 ChatGPT는 학생이 "개념을 모르겠다"고 하면 교과서식 정의와 5문단짜리 긴 증명을 일방적으로 쏟아내어 인지 과부하(Cognitive Overload)를 일으키고 공부 흐름을 끊음. 학생이 막힌 '단 하나의 개념 병목'을 1분 만에 직관적으로 깨우치고 즉시 원래 문제 풀이로 복귀시키는 초경량 드릴다운 프레임워크가 필요함.

---

## 1. 3단계 개념 드릴다운 작동 구조 (3-Step Micro Drill-Down)

```
[ 학생: "② 개념부터 알고 싶어요" 클릭 또는 개념 결손 감지 ]
       │
       ▼
┌─────────────────────────────────────────────────────────────┐
│ 【 1단계: 3줄 직관 요약 (Intuitive Summary) 】                 │
│  - 어려운 수학 정의나 증명 배제                              │
│  - 일상어와 쉬운 직관으로 "지금 이 문제에 필요한 핵심 원리"만 3줄 압축 │
├─────────────────────────────────────────────────────────────┤
│ 【 2단계: 1-Step 미니 확인 질문 (Micro Check Quiz) 】          │
│  - 전체 문제를 풀게 하지 않고, 방금 설명한 공식의 1단계 연산만 출제 │
│  - 5지선다 버튼 클릭으로 5초 만에 성공 경험(도파민) 제공     │
├─────────────────────────────────────────────────────────────┤
│ 【 3단계: 원문항 즉시 복귀 (Fast Return) 】                   │
│  - "방금 맞힌 그 조각을 원래 문제에 대입해서 마저 풀어볼까요?" │
│  - 하위 학년에 머무르지 않고 현재 수능 문항 완풀로 즉시 연결  │
└─────────────────────────────────────────────────────────────┘
```

## 2. 실제 대화 시나리오 예시 (수능 1번 지수법칙)

* **문제**: $9^{1/4} \times 3^{-1/2}$ 의 값은?
* **유저**: `[② 개념부터 알고 싶어요]` 클릭

> **🤖 AI 튜터 (1단계: 3줄 직관 브리핑)**  
> "거듭제곱끼리 곱할 때는 **밑(아래 숫자)을 똑같이 맞춘 뒤, 지수(위 숫자)를 더하면** 끝나요.  
> $9$는 $3^2$이니까, 밑을 $3$으로 먼저 통일해 주는 게 핵심이에요."

> **🤖 AI 튜터 (2단계: 1-Step 확인 질문)**  
> "그럼 가볍게 한 칸만 확인해 볼까요?  
> $9^{1/4}$을 밑이 $3$인 거듭제곱으로 바꾸면 몇 제곱이 될까요?  
> ① $3^{1/2}$  ② $3^{1/4}$  ③ $3^1$  ④ $3^2$  ⑤ $3^{-1/2}$"

* **유저**: `①` 클릭 (성공)

> **🤖 AI 튜터 (3단계: 원문항 복귀)**  
> "완벽해요! $(3^2)^{1/4} = 3^{2/4} = 3^{1/2}$으로 깔끔하게 바뀌었네요.  
> 그럼 이제 원래 식 $3^{1/2} \times 3^{-1/2}$에서 지수끼리 더해서 최종 답을 내볼까요?"

## 3. 심각한 결손 발생 시의 릴레이 드릴다운 (Deep Drill-Down)

만약 학생이 2단계 확인 질문마저 틀렸을 경우(`CAT_2 Depth >= 2`):
1. 과거 학년 전체 복습을 강제하지 않고, 바로 아래 학년 개념(예: 중2 거듭제곱의 곱셈 법칙)으로 딱 1단계만 더 내려가서 질문형 힌트 제공.
2. 해결되는 즉시 다시 고3 원래 문제로 역순으로 껑충 뛰어올라와 복귀.

---

## 4. 기대 효과
* 장황한 해설로 인한 이탈률 0%.
* 5초짜리 미니 퀴즈 성공으로 학생의 학습 자신감 회복.
* `stem-tutor-agent`의 정밀 결손 추적과 100% 맞물려 '가장 빠른 원문항 탈출' 실현.
