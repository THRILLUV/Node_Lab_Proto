# ADR-004: 웹 표준 기반 모바일 컴패니언(카메라 오버레이 + 실시간 양방향 세션 동기화) 아키텍처

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
PC에서 문제를 풀면서 스마트폰을 손풀이 카메라 및 무전기(Hold-to-Talk) 마이크로 사용하는 듀얼 디바이스 경험을 제공할 때, 별도의 네이티브 앱(iOS/Android) 설치 강제 없이 순수 모바일 웹(PWA) 기술만으로 카메라 배경, 글래스 UI 오버레이, 기기 간 실시간 화면 동기화가 가능한지 여부와 구현 아키텍처를 정의함.

## 결정
**순수 웹 표준 기술(Web Media API + CSS Glass + WebSocket) 기반 컴패니언 아키텍처 채택**

1. **카메라 배경 및 오버레이 (100% 웹 표준)**:
   - 후면 카메라 스트림: `navigator.mediaDevices.getUserMedia({ video: { facingMode: 'environment' } })`
   - 전체 화면 `<video>` 태그 위에 CSS `position: fixed`, `backdrop-filter: blur(12px)` 글래스 카드를 레이어링하여 책상 위 노트를 비추면서도 상단에 문제 정보와 AI 대화가 반투명하게 떠 있도록 구현.

2. **기기 간 실시간 양방향 상태 동기화 (WebSocket)**:
   - PC 웹과 모바일 웹이 동일한 `session_id` 룸을 구독.
   - **PC ➔ 폰**: PC에서 1번 문항 ➔ 2번 문항으로 탭을 바꾸면, 50ms 내에 폰 카메라 오버레이 상단의 문제 카드와 태그가 새로고침 없이 즉시 전환됨.
   - **폰 ➔ PC**: 폰에서 붉은색 버튼을 눌러 손풀이를 캡처하고 음성 질문을 하면, PC 화면의 메인 챗봇 스트림에 손풀이 이미지와 STT 텍스트가 즉시 렌더링됨.

3. **무전기식 토크백 마이크 (Hold-to-Talk)**:
   - 붉은 버튼 `pointerdown` 시 마이크 녹음 시작(`MediaRecorder` / Web Audio API) ➔ `pointerup` 시 녹음 종료 및 오디오 스트림 전송.

4. **페어링 방식**:
   - 기본: 동일 구글 계정 로그인 시 상단 "현재 진행 중인 세션 연결" 바 원터치 입장.
   - 보조: PC 화면 일회용 QR 코드 스캔으로 무로그인 즉시 페어링 지원.

## 결과 및 기대효과
- 앱스토어 심사나 앱 다운로드 설치 장벽 없이, 링크 클릭/QR 스캔 한 번으로 3초 만에 듀얼 디바이스 환경 구축.
- PC의 대화면 가독성과 스마트폰의 직관적인 입력(카메라/마이크)을 하나로 결합한 차별화된 AX 경험 달성.
