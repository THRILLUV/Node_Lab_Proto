# ADR-011: 수능 수학을 넘어 전 과목(과학·자격증·어학·공무원)으로 확장 가능한 범용 자습 세션 OS 아키텍처

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
NodeLab은 수학(수능 수학)을 초기 MVP로 삼아 가장 까다로운 기호수학 검증(SymPy)과 논리 결손(CAT) 감사를 검증하지만, 근본적인 제품의 지향점은 시험 종류와 과목에 구애받지 않고 어떤 시험지든 **'무한한 실전 훈련장'**으로 변환하는 **범용 학습 세션 OS(Universal Study Session OS)**로의 확장성을 갖추어야 함.

---

## 1. 전 과목/도메인 확장 매트릭스 (Domain Expansion)

NodeLab의 `[PDF 분할 ➔ 1문항 고정 ➔ 5선택지 ➔ 논리 감사 ➔ 맞춤형 모의고사]` 루프는 과목별 '검증 도구(Tool)'만 교체하면 즉시 전 과목으로 확장됩니다.

| 도메인 | 대상 시험 / 과목 | 논리 감사 및 변형 생성 방식 | 검증 도구 (Verifier) |
|---|---|---|---|
| **수학 (현재 MVP)** | 수능 수학, 편입 수학, 검정고시 | 수식 단계별 동치 검산, 결손 라인 핀포인트, 수치 변형 문제 | SymPy + Gemini 블라인드 재풀이 |
| **자연과학 (STEM)** | 물리, 화학, 생명과학, 지구과학 | 물리 법칙/화학 반응식/계산 조건 변형, 실험 데이터 표 수치 변형 | SymPy + 도메인 규칙 라이브러리 |
| **국가 전문 자격증** | 공인중개사, 정보처리기사, 세무사 | 법령 조항·사례형 판례 지문 변형, 계산 공식 수치 치환, 오답 보기 순열 | 규칙 기반 법령/표준 교차 검증 |
| **어학 / 수능 영어** | 수능 영어, 토익, 토플, 텝스 | 지문 문맥·어휘 동의어 치환, 빈칸 추론 위치 변경, 문장 삽입 순서 셔플 | NLTK/SpaCy 구문 분석 + LLM |
| **적성 / 공무원 시험** | PSAT, LEET, NCS 직업기초능력 | 언어논리 명제 반례 생성, 수리자료해석 도표 수치 변형 | Z3 SMT Solver (논리식 검증) |

---

## 2. 왜 수학에서 성공하면 전 과목 확장이 쉬운가?

1. **가장 어려운 난이도부터 정복 (Hardest-First Strategy)**:
   - 수학은 '단 1개의 기호/부호만 틀려도 전체가 붕괴'하는 가장 엄격한 결정론적 영역입니다.
   - 수학에서 SymPy와 이중 블라인드 검증으로 무결성을 입증하면, 텍스트 기반인 자격증이나 영어는 훨씬 적은 연산 비용으로 쉽게 확장됩니다.
2. **동일한 사용자 경험(UX) 유지**:
   - 학생은 공인중개사 시험지를 올리든, 수능 물리를 올리든, 토익 RC를 올리든 똑같이 **"1문항 고정 + 5대 선택지 + 무한 셔플/변형 모의고사"**의 직관적인 UI를 그대로 사용합니다.

---

## 3. 비즈니스 및 최종 IR 피칭 가치

* **시장 규모(TAM)의 100배 확장**:
  * 고등 수능 수학 시장(연 40만 명) ➔ 성인 자격증/공무원/어학 자습 시장(연 500만 명 이상).
* **AI 교육 서비스의 최종 지향점**:
  * "단순히 해설을 보여주는 정적 문제집"의 시대를 끝내고, **"어떤 시험지든 올리면 실시간으로 살아 움직이는 개인 전담 훈련장"**으로 거듭나는 플랫폼 독점력 확보.
