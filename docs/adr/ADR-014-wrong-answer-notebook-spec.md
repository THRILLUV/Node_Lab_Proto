# ADR-014: CAT 결손 태그 기반 스마트 오답노트 화면 및 복습 훈련 루프 설계 명세

## 상태
확정 (Accepted) - 2026-09-01
- 학생 화면 카피·뱃지는 **ADR-021**을 따른다. `CAT_2` 같은 내부 코드는 오답노트에 노출하지 않는다.

## 맥락
기존 문제집/앱의 오답노트는 단순히 틀린 문제 사진과 해설을 나열하는 정적 보관함에 불과하여 학생이 능동적으로 복습하지 않음. NodeLab의 오답노트는 **"내가 왜 틀렸는지(CAT 결손 코드)를 기준으로 큐레이션하고, 취약점만 골라 변형 문제로 즉시 재훈련하는 액티브 복습 허브"**로 설계되어야 함.

## 2. 오답 카드 데이터 필드 및 인터랙션

1. **오답 카드 핵심 정보**:
   - 문항 정보: `[2026 수능 3번]` `[2점]` `[지수법칙]`
   - 원인 뱃지(사람말): `[개념이 안 붙음]`, `[식을 못 세움]`, `[계산 실수]`, `[조건 누락]`
   - 1줄 원인 요약: AI가 진단했던 최초 결손 이유 (예: *"밑 통일 누락"*)
   - 마스터 상태: `[빨강: 미해결]` ➔ `[노랑: 1회 변형 풀이]` ➔ `[초록: 마스터 완료]`
2. **원클릭 복습 액션 3가지**:
   - `[✏️ 다시 풀기]`: 정답/해설을 가린 채 원본 문제를 캔버스에 다시 풂.
   - `[🔀 변형 문제]`: 내가 틀렸던 그 결손 포인트의 숫자 변형 문제를 즉시 생성하여 풀이.
   - `[✅ 마스터 완료]`: 스스로 완벽히 안다고 판단 시 활성 오답 목록에서 보관함으로 이동.

## 3. 오답노트 연계 킬러 기능: "취약점 집중 모의고사"

오답노트 상단의 `[⚡ 내 취약점만 5문제 훈련장 생성]` 클릭 시:
* 내부 라벨이 CAT_2·CAT_3로 confirmed된 카드의 `concept_name`만 모아, **숫자가 바뀐 5~10문제짜리 약점 훈련장을 생성**. 화면에는 CAT 코드를 쓰지 않는다.
* 약점 모의고사를 100점 맞으면 오답노트의 해당 항목들이 일괄 `[마스터 완료]` 처리됨.

---

## 4. R&R 연동 명세
* **회원 및 유입 (박태희)**: 좌측 사이드바 `오답노트` 클릭 시 2분할 뷰파인더/그리드 UI 렌더링.
* **AI 코어 (김홍)**: 오답 카드 클릭 시 해당 문항의 CAT 진단 로그 및 직전 3단계 대화 기록 바인딩.
* **과금 및 수익화 (변희웅)**: 오답 큐레이션은 Free 무료 제공, '취약점 집중 모의고사 무제한 생성'은 Pro 전용 기능.
* **그로스 및 마케팅 (손소연)**: 오답이 3개 이상 쌓였을 때 D+2 저녁 8시 *"어제 틀렸던 시그마 문제, 변형 1문제로 복습해볼까요?"* 리마인드 푸시 발송.
