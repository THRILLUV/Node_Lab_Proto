# ADR-005: 비용 최적화형 비대칭 생성-검증자(Generator-Verifier) 변형 문제 무한 생성 아키텍처

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
유료 구독 유저에게 '무제한 파생 응용문제 완풀'을 제공하기 위해서는 API 호출 비용을 극한으로 낮추면서도, AI 환각(수학적 오류, 분모 0, 성립하지 않는 조건)을 100% 차단하는 무결성 가드레일이 필요함.

## 결정
**비대칭 생성-검증자 (Generator-Verifier) 2계층 아키텍처 채택**

1. **1계층: 초저가 생성자 (Generator - DeepSeek V4 Flash / OpenCode Go)**
   - 역할: 원본 문제의 핵심 논리 뼈대(SOP)를 바탕으로 숫자·미지수·정답을 바꾼 변형 문제 초안과 해설을 실시간 대량 생성.
   - 비용: $0.14 / 1M tokens (건당 약 0.3~0.5원 수준으로 무제한 출제 가능).

2. **2계층: 이중 무결성 검증자 (Verifier - SymPy 로컬 엔진 + 고지능 가드레일)**
   - **1차 결정론적 검증 (SymPy)**:
     - 생성된 수식의 수학적 해(Root), 특이점(분모 0), 고등 교육과정 범위(자연수/유리수 해) 만족 여부를 로컬 CPU(0원)로 즉시 계산.
   - **2차 지능형 블라인드 검증 (Gemini 3.7 / 고지능 모델)**:
     - 생성자가 주장한 정답을 가린 채(Blind Re-solve), 문제 지문만 보고 독립적으로 문제를 다시 풀어 정답과 문제 성립 여부 최종 일치 확인.

3. **Fallback & Retry 루프**:
   - 검증 통과 시: 즉시 학생 화면 문제판에 KaTeX로 렌더링.
   - 검증 불일치 시: 유저에게 노출하지 않고 백그라운드에서 초저가 생성자가 1회 즉시 재생성.

## 결과 및 기대효과
- **원가 극단적 절감**: 고지능 모델로 문제를 직접 생성하는 대신, 검증만 수행하므로 문제 생성당 총비용 1원 미만 유지.
- **무제한 구독 마진 85% 이상 방어**: 헤비 유저가 수백 문제를 풀어도 월 AI 원가가 1천 원대에 수렴하여 비즈니스 모델의 경제성(Unit Economics) 완전 확보.
- **교육 논리 감사(Audit) 철학의 실체화**: 'AI가 생성하고, AI가 감사하여 무결성을 보증한다'는 서비스 핵심 가치와 완벽 부합.
