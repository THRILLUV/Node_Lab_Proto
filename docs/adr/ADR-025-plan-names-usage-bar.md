# ADR-025: 요금제 이름, 횟수 한도, 사용량 바(100%), 충전 팩

## 상태
확정 (Accepted) - 2026-09-02
- 박태희 × 변희웅 대화 + 이후 그릴 결정.
- 화면 숫자는 **크레딧이 아니라 사용량 바 + 횟수**.
- ADR-009의 게스트 3 / 가입 후 한도는 이 문서 한도표로 갱신한다. 9,900원 구독 골격은 유지.

## 결정 요약
1. 이름: 비회원 / **라이트** / **베이직(9,900)** / **헤비(29,900)**. 프로·VIP 안 씀.
2. 진짜 밸브는 **횟수 한도**. 3만·10만·50만 크레딧은 쓰지 않음.
3. 메인 게이지는 ChatGPT식 **100% 바**. 손풀이 월 한도와 1:1. 대화 턴은 바에 안 넣음.
4. 라이트는 소액 충전 없음 → 베이직 업셀. 베이직·헤비만 이번 달 횟수 팩.
5. 라이트 OCR은 메인과 같은 Gemini. 싸구려 비전으로 차별하지 않음.
6. 비회원만 무료/로컬 저성능 + 미저장. 원가 0.

## 1. 한도표

| | 비회원 | 라이트 | 베이직 9,900 | 헤비 29,900 |
|---|---|---|---|---|
| 저장·오답노트 | 안 됨 | 됨 | 됨 | 됨 |
| 모델 | 무료/로컬. 우리 지출 0 | 메인 (Gemini OCR, Spark/DeepSeek 대화·출제) | 같음 | 같음 |
| 업로드 일 | 방문당 3 | 10 | 없음 | 없음 |
| 업로드 월 | — | 300 | 300 | 1,000 |

## 2. 사용량 바

- 월초 **100% = 해당 플랜 손풀이 월 한도** (라이트 150, 베이직 600, 헤비 1,000).
- 손풀이 1회 확정(OCR 확인 커밋)마다 `100 / 월한도` %p 감소.
- 옆에 보조 카피: `손풀이 12/20` (일 한도가 있는 플랜) · 응용은 버튼에서 `이 문항 2/3`.
- **대화 턴은 바에서 안 깎는다.** 그 문항 손풀이/응용 1회에 포함. 한 문항 대화가 비정상적으로 길면 “이 문제는 여기까지”로 컷. 한글 토큰 1.4~2배는 원가 장부에만.
- 업로드·응용 한도는 바와 별도 카운터. 한 바에 OCR+대화+응용을 섞지 않는다.
- 가드레일 실패(비수학, 빈 손풀이 등)는 바와 횟수에 안 넣는다.

카피 예: 한도 도달 시 `오늘 손풀이 한도를 다 썼어요` (크레딧/대화량이라고 하지 않음).

---

## 3. 0% · 충전

- **라이트:** 충전 상품 없음. `베이직으로 이어 풀기`.
- **베이직·헤비:** 구독 유지 + **횟수 팩** (퍼센트·크레딧 아님).
  - 예: 손풀이 20회, 응용 50회.
  - **이번 구독 월에만** 유효. 해지·월 리셋 시 소멸. 베이직+충전만 쌓아서 헤비를 우회하지 못하게.
- 화면: `손풀이 20회 더하기` . “크레딧 5만” 금지.

* 비회원 엔드포인트는 유료 프로덕션 API 키와 완전히 분리된 별도 환경변수(`GOOGLE_FREE_TIER_KEY`, `OPENCODE_FREE_KEY`)로 서빙.
* 비회원 요청이 폭증하여 무료 쿼터가 소진되면 시스템이 안전하게 429 지연 안내를 띄우며, 회사의 금전적 손실은 0원으로 완벽 방어.
