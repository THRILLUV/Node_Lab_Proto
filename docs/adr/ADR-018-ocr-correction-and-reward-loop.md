# ADR-018: 손글씨 오인식 보정 UI(HITL), 2단계 확인 플로우 및 사용자 기여 보상(크레딧 리워드) 정책

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
손글씨 OCR은 필체·조명·카메라 각도에 따라 오인식(Misrecognition)이 발생할 수밖에 없음. 오인식을 시스템의 일방적 에러로 방치하면 유저 이탈로 이어지므로, 유저가 손쉽게 오독을 바로잡을 수 있는 보정 모달을 제공하고, 수정 기여에 대해 즉각적인 보상(무료 크레딧)을 지급하여 부정적 경험을 긍정적 참여 경험으로 전환하는 피드백 루프를 정의함.

---

## 1. 2단계 손풀이 인식 검증 플로우 (Preview & Verification)

손풀이 사진을 올리자마자 바로 채점으로 직행하지 않고, **0.5초 프리뷰 카드**를 띄워 인식 정합성을 유저와 상호 확인합니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 📝 방금 올리신 손풀이를 이렇게 읽었어요                     │
├──────────────────────────────────┬──────────────────────────┤
│ [왼쪽: 원본 손글씨 크롭 사진]      │ [오른쪽: AI가 변환한 수식] │
│  (학생이 찍은 노트 영역)         │  Step 1: 9^(1/4) = 3^(1/2)│
│                                  │  Step 2: 3^(1/2) * 3^(-1/2)│
├──────────────────────────────────┴──────────────────────────┤
│ "손풀이가 정확하게 인식되었나요?"                           │
│  [👍 네, 맞아요 ➔ 바로 첨삭받기]  [✏️ 틀린 부분 직접 고치기]  │
└─────────────────────────────────────────────────────────────┘
```

---

## 2. 오인식 보정 UI (Quick-Fix Modal)

`[✏️ 틀린 부분 직접 고치기]`를 눌렀을 때:
* 전체를 다시 타이핑하게 하지 않고, **잘못 읽힌 특정 줄(Step N)이나 숫자만 클릭하여 키패드로 3초 만에 수정**.
* 만약 사진이 너무 흐리거나 잘려서 복구가 불가능할 경우:
  * 토스 톤 안내: *"글씨가 조금 흐리거나 가려졌어요. 밝은 곳에서 반듯하게 한 번만 다시 찍어주실 수 있나요?"* ➔ `[📸 다시 촬영하기]`

---

## 3. 오인식 개선 기여 보상 정책 (Reward & Gamification)

학생이 오인식된 수식을 직접 수정하거나, 더 또렷한 글씨로 다시 업로드하여 시스템 개선에 기여했을 때 즉각적인 보상을 지급합니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 🎁 인식 개선에 참여해 주셔서 감사해요!                      │
│  - 소중한 수정 데이터로 AI 인식 모델이 한층 더 똑똑해졌어요.   │
│  - 감사의 마음으로 【보너스 무료 풀이 1회 크레딧】을 충전해 드렸어요!│
│  ➔ [ 보너스 크레딧 받고 학습 이어가기 ]                     │
└─────────────────────────────────────────────────────────────┘
```

* **보상 기준**:
  1. AI 신뢰도(Confidence) < 0.8인 상태에서 유저가 수식을 바르게 수정한 경우 ➔ **보너스 1회 풀이 크레딧 즉시 지급**.
  2. 오인식 제보 누적 5회 달성 시 ➔ **[정밀한 교정자] 프로필 뱃지 부여**.

---

## 4. 비즈니스 및 데이터 자산화 효과 (Data Asset Flywheel)

1. **오류 경험의 긍정적 전환**:
   - 시스템 오류를 마주했을 때 유저가 화를 내는 대신 "어? 수정하면 1문제 무료로 더 푸네!"라는 이득 경험(Gain)으로 치환.
2. **최고급 한국어 손글씨 파인튜닝 데이터셋 자동 확보**:
   - `[학생 손글씨 원본 이미지 ↔ 유저가 직접 검수한 100% 정답 LaTeX 라벨]` 쌍이 매일 수천 건씩 DB에 자동 누적됨.
   - 추후 자체 경량 OCR 모델 파인튜닝 시 라벨링 외주 비용(수천만 원)을 0원으로 절감.
