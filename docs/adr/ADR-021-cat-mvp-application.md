# ADR-021: CAT v0.6를 NodeLab MVP 루프에 적용하는 서류 고정 (구현은 후순위)

## 상태
확정 (Accepted) - 2026-09-01
- 성격: **제품/기획 서류 고정**. 백엔드·프로토 HTML·Gemini 실호출에는 지금 붙이지 않는다.
- 원본 SOP: 김홍 CAT 진단 체계 v0.6 (`CAT.docx`)
- 이 문서가 MVP 적용 범위의 SoT다. ADR-002 / 013 / 014 / 020과 충돌하면 **이 문서를 따른다.**

## 맥락
CAT 4축은 쓸 가치가 있다. 다만 Master 지표 전체와 게이지·계통도·등급 시뮬레이션은 MVP가 아니다.
MVP에서 CAT는 **손풀이 제출 이후, 세션 백엔드가 다음 한 수를 가르는 방아쇠**다. 학생 화면에는 코드를 내지 않는다.

---

## 0. 구현 시점 규칙

- 클릭 프로토(`nodelab-proto.html`)는 계속 화면 연극이다. CAT 실분류를 넣지 않는다.
- 나중에 구현할 때 붙이는 위치는 한 곳뿐이다: **손풀이 인식 확인이 끝난 뒤의 진단 스텝.**
- 온보딩 5지선다는 CAT를 초기화하지 않는다. 세션 기본값(목적/입력물/오늘 모드)만 저장한다.

---

## 1. MVP에서 쓰는 것 / 안 쓰는 것

### 쓴다 (구현 때 필수)

| 필드 | 출처 | MVP 용도 |
|---|---|---|
| `primary_category` | CAT_1~4 또는 null | 다음 UX 분기 |
| `prerequisite_depth` | CAT_2일 때만 1~5 | 드릴다운을 한 칸만 더 내릴지 |
| `computation_error_type` | CAT_4일 때만 SIGN / ARITHMETIC / EXPANSION | 핀포인트 카드 문구 |
| `encoding_error` | primary가 null일 때만 | 최종 조건 누락 안내 |
| `status` | confirmed / deferred | 애매하면 약한 힌트만 |
| `confidence` | 0~1 | 0.6 미만이면 확정 금지 |
| `evidence_quote` | 학생 원문 그대로 | 카드에 인용. 창작 금지 |
| `error_step_index` | 최초 어긋난 줄 | “2번째 줄” 표시 |
| `concept_name` | 문항 메타 (예: 지수법칙) | 오답노트·축하 카피. 지식그래프 없음 |
| `rule_gap_flag` | true/false | 관리자 예외 큐로만 |

### 안 쓴다 (백로그)

- `goal_identification_score`, `condition_coverage_rate`, `strategy_deviation_index`, `is_algebraic_equivalent`, `fork_point_index`
- 온보딩 손글씨 레벨테스트로 CAT 초기화
- 학생/오답노트에 `CAT_2` 코드 노출
- 홈 3대 역량 게이지, 선수개념 계통도, 수능 등급 시뮬레이션
- 개념 지식그래프 Depth 노드 전체
- Hong 문서의 미설계 규칙 `X-1' / X-2'` (이력 기반 재가중). MVP는 콜드스타트 규칙 X-0~X-3, 1-a를 그대로 쓴다.

## 2. CAT이 도는 순간 (5선택지 매핑)

CAT는 **손풀이 사진/캔버스가 있고, OCR 확인을 통과한 뒤**에만 돈다.

| 5선택지 | CAT 실행 | 동작 |
|---|---|---|
| 1 답만 빠르게 채점 | 안 함 | 정답 대조만. 손풀이 없으면 원인을 짐작하지 않는다. |
| 2 개념부터 알고 싶어요 | 안 함 | 유저가 먼저 개념을 달라고 한 것. ADR-013 드릴다운만. 진단 라벨을 만들지 않는다. |
| 3 내 손풀이 봐주세요 | **함** | OCR 확인 → CAT → 아래 분기 |
| 4 비슷한 문제 더 풀기 | 조건부 | 이 문항의 직전 CAT가 있으면 그 `concept_name`으로 숫자 변형. 없으면 원본 구조만 변형. |
| 5 직접 질문하기 | 조건부 | 손풀이 첨부가 있으면 CAT. 텍스트만이면 자유 질문. |

빠른 채점에서 틀려도 CAT를 만들지 않는다. **풀이 없는 정답은 레벨/원인 확정이 아니다.**

## 3. 손풀이 경로의 고정 순서 (나중에 구현 순서)

```
[3 내 손풀이 봐주세요]
        │
        ▼
[OCR 프리뷰] 손풀이가 정확하게 인식되었나요?     ← ADR-018
  👍 맞아요  /  ✏️ 줄만 고치기  /  다시 촬영
        │ (확인된 텍스트만 진단 입력)
        ▼
[CAT v0.6 SOP]
  1-a 검산 → X-0 생략단계 → X-3 CAT_2 우선 → X-1 / X-2
  첫 결손 1개만 primary. 겹치면 더 앞 줄을 택한다.
        │
        ├─ status=deferred 또는 confidence<0.6
        │     → 확정하지 않음. CAT_3급 힌트 1줄만. 오답노트 미등록.
        │
        ├─ primary=null, encoding_error=true
        │     → “계산은 맞아요. 마지막 조건만 빠졌어요.”
        │
        ├─ CAT_1 → 지문 조건 하이라이트 + 한 줄 질문
        ├─ CAT_2 → ADR-013 3단계 드릴다운 (Depth는 한 칸만 더 내림)
        ├─ CAT_3 → 관계식 힌트 1줄
        └─ CAT_4 → 틀린 줄 원샷 대조 카드
        │
        ▼
[오답노트] confirmed 이고 primary가 null이 아닐 때만 1장 생성
[완풀] 원문항 복귀 후 맞히면 탭 초록 + 담백한 축하. 코드 없음.     ← ADR-007
```

## 4. 학생에게 보이는 말 (코드 금지)

내부는 `CAT_2`로 저장하고, 화면은 아래만 쓴다.

| 내부 | 화면 한 줄 | 버튼 |
|---|---|---|
| CAT_1 | 문제에서 이 조건을 놓쳤어요 | 조건 다시 보고 풀어보기 |
| CAT_2 | 이 공식만 한 칸 확인하고 원래 문제로 갈게요 | 공식 확인하고 이어 풀기 |
| CAT_3 | 개념은 있는데, 이 문제 식으로 바꾸는 칸에서 막혔어요 | 관계식 힌트 보기 |
| CAT_4 SIGN | 2번째 줄에서 부호가 바뀌었어요 | 고쳐서 다시 계산하기 |
| CAT_4 ARITHMETIC | 2번째 줄 계산만 다시 보면 돼요 | 그 줄만 다시 계산하기 |
| CAT_4 EXPANSION | 전개하는 줄에서 항이 하나 빠졌어요 | 그 줄만 다시 전개하기 |
| encoding_error | 계산은 맞아요. 마지막 조건만 빠졌어요 | 조건 맞춰 답 고치기 |
| deferred | 이 줄부터 한 칸만 같이 볼게요 | 힌트 보고 이어 풀기 |

오답노트 필터/뱃지도 코드 대신 **개념이 안 붙음 / 식을 못 세움 / 계산 실수 / 조건 누락**.

## 5. 완성도를 여기서 올린 결정 (기존 서류 빈칸)

1. **온보딩 ≠ CAT.** 목적 매칭만. 손풀이 없는 정답으로 숙달을 올리지 않는다.
2. **OCR 통과 전 CAT 금지.** 오인식 위에 진단하면 가짜 학습기록이 쌓인다.
3. **한 문제 한 결손**은 통계가 아니라 UX 규칙이다. 첫 어긋난 줄만 고친다.
4. **애매하면 라벨하지 않는다.** deferred는 오답노트·숙달 점수에 넣지 않는다.
5. **`concept_name`은 문항 태그를 그대로 쓴다.** MVP에 중학 계통도를 만들지 않는다. Depth 숫자는 CAT_2 드릴다운 깊이 조절에만 쓴다.
6. **누적 지표는 3개만.**
   - 개념별 `wrong_count` / `recovered_count`
   - 최근 confirmed `primary_category`
   - 오답 카드 상태: 미해결 → 변형 1회 → 마스터
7. **선택지 2(개념)와 CAT_2 드릴다운은 같은 화면 패턴을 재사용**하되, 전자는 유저 요청, 후자는 진단 결과다. 로그에 `source=user_request|diagnosis`를 남긴다.
8. **관리자(장명희) MVP:** `rule_gap_flag=true` 또는 `deferred` 건만 예외 큐에 쌓는다. 히트맵·코호트는 2차.

---

## 6. 오답노트 (ADR-014 수정 적용)

학생 카드에 넣는 값:
- 문항 정보, `concept_name`, 사람말 원인 1줄(`evidence_quote` 기반), 상태
- 다시 풀기 / 숫자 변형 / 이해했어요

넣지 않는 값:
- `CAT_2`, Depth 숫자, confidence, JSON

취약점 5문제 훈련장: confirmed CAT_2·CAT_3 카드의 `concept_name`만 모아 변형. **Pro.** 열람은 Free.

---

## 7. Audit 리포트 / 게이지 / 계통도

서류상 방향은 유지하되 **MVP 화면이 아니다.**
나중에 붙일 때 입력은 이 문서 1절 필드 + 누적 3개만 사용한다. 등급 예측 문구는 넣지 않는다.

## 8. 홍 님 SOP와 제품의 역할 분담

| 담당 | 나중에 구현할 일 |
|---|---|
| 김홍 | v0.6 판정 절차를 진단 프롬프트/JSON으로 이식. 출력은 1절 필드만. |
| 박태희 | 5선택지·OCR 확인·분기 화면·오답노트 사람말 카피. 코드 미노출. |
| 변희웅 | CAT 호출은 손풀이 확정 1회에만 과금 카운트. deferred 재시도는 같은 제출로 본다. |
| 장명희 | rule_gap / deferred 예외 큐. |
| 손소연 | 오답 3장 이상일 때 복습 리마인드. 카피에 CAT 코드 금지. |
