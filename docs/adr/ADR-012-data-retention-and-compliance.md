# ADR-012: 개인화 학습 데이터 3년 보관, 저작권 컴플라이언스 및 B2B 데이터 자산화 정책

## 상태
확정 (Accepted) - 2026-09-01

## 맥락
수험생(고1~고3, N수생, 편입생)의 실제 학습 라이프사이클(1~3년)을 고려할 때, 7일 단기 파기는 과거 오답 복습과 장기 성취도 추적을 불가능하게 만듦. 학생에게는 3년간 안전한 개인 학습 자산을 보장하면서도 출판사 저작권 침해를 원천 차단하고, 누적된 결손 빅데이터를 B2B 자산으로 전환하는 운영 정책이 필요함.

---

## 1. 3년 보관 및 개인화 학습 자산화 정책

1. **보관 기간 (3년)**:
   - 학생이 업로드한 문제집 PDF, 크롭 문항, 손풀이 필기 이미지, AI 대화 기록은 **가입일 또는 세션 생성일로부터 최대 3년(또는 회원 탈퇴 시까지)** 안전하게 보관됨.
   - 유저는 고등학교 재학 기간(3년) 동안 과거에 풀었던 모든 기출 세션과 오답노트를 언제든 다시 열어 복습 가능.
2. **프라이빗 보안 격리 (저작권 100% 방어)**:
   - 학생이 올린 문제집 원본은 오직 **해당 유저의 개인 격리 스토리지(`user_id` 전용 공간)** 안에서만 서비스되며, 타인에게 공유되거나 공용 문제은행으로 재배포되지 않음(저작권법 공정이용 사적 복제 준수).
3. **즉시 삭제 권리 보장**:
   - `마이페이지 > 개인정보 및 데이터 삭제`에서 유저가 원할 경우 언제든 1초 만에 원본 이미지 및 세션 전량 영구 파기 가능.

---

## 2. B2B 교육 데이터 자산화 파이프라인

3년 동안 누적되는 방대한 풀이 데이터 중, **개인정보를 완전히 제거한 비식별 메타데이터**를 가공하여 2차 B2B 수익원으로 확장합니다.

```
[ 학생 풀이 원본 데이터 (3년 프라이빗 보관) ]
       │
       ▼ (비식별화 & 수식 메타데이터 추출 엔진)
【 B2B 교육 결손 인텔리전스 DB (영구 자산화) 】
  - 문항별 최초 결손 라인 통계 (예: 2026 수능 3번 2행 오답률 42%)
  - 개념 간 연쇄 결손 매트릭스 (예: 지수함수 결손자 중 68%가 중2 지수법칙 결손)
  - CAT_1~4 에러 코드 분포 및 평균 돌파 턴 수
       │
       ▼ (B2B 제휴 및 데이터 판매)
  - EBS / 대형 입시 출판사 (메가스터디, 대성 등) ➔ 차세대 교재 집필용 데이터 공급
  - AI 디지털 교과서(AIDT) 발행사 ➔ 학생 결손 진단 알고리즘 파트너십
```

---

## 3. R&R 연동 및 컴플라이언스 명세

* **회원 및 유입 PM (박태희)**: 이용약관 제4조 및 개인정보 수집/이용 동의서에 '학습 데이터 3년 보관 및 탈퇴 시 즉시 파기' 명시.
* **운영 및 백오피스 PM (장명희)**: 관리자 페이지 내 '3년 경과 데이터 자동 파기 배치(Cron)' 및 '사용자 데이터 즉시 삭제 요청 처리 큐' 구현.
* **과금 및 수익화 PM (변희웅)**: B2B 데이터 자산화 및 기업용 API 제휴 비즈니스 모델(2차 BM) 설계안 수립.
