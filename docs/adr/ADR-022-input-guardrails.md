# ADR-022: 입력 가드레일 (비수학 차단 + MVP 동반 게이트)

## 상태
확정 (Accepted) - 2026-09-01
- 성격: 기획 서류 고정. 백엔드·프로토에는 지금 붙이지 않는다.
- 수학 판정 게이트는 사용자 확인(2026-09-01)으로 잠근다.

## 맥락
NodeLab MVP는 수능·내신·편입 수학 자습기다. 국어/영어/셀카/자소서를 받아 해설하면 제품이 일반 챗봇이 되고, CAT·SymPy·변형 원가만 나간다. 수학이 아닐 때는 정중히 멈추고, 본 루프를 태우지 않는다.

---

## 1. 잠근 방식: 분류 후 분기 (하드 거절도, 무조건 시도도 아님)

OCR 확인·CAT보다 **앞**에서 한 번만 본다.

```
업로드 (PDF / 사진 / 손풀이) 또는 세션 채팅
        │
        ▼
[게이트 0] 수학 문항인가?
        │
        ├─ math_problem  → 기존 OCR 확인 → CAT / 5선택지
        ├─ maybe_math    → 한 번만 확인 후 예이면 수학으로 진행
        ├─ not_math      → 본 루프 스킵. 사용량 안 깎음
        └─ unreadable    → 재촬영/다른 파일. 사용량 안 깎음
```

판정은 이미지를 이미 보는 Gemini 한 번의 라벨이면 된다. 별도 분류 모델을 두지 않는다.

| 라벨 | 예 | 화면 (해요체, 코드 비노출) | 시스템 |
|---|---|---|---|
| math_problem | 수능/내신 수학 문항 | 없음. 통과 | 본 루프 |
| maybe_math | 물리 계산, 초등 연산, 표만 있음 | 수식이 있긴 한데, 수능 수학이 아닐 수 있어요. 수학으로 풀어볼까요? `[수학으로 풀어보기]` `[다른 장 올리기]` | 예 1회면 그 세션은 수학 |
| not_math | 국어, 영어, 셀카, 단어장 | 이 장은 수학 문제로 안 보여요. 지금은 수능·내신·편입 수학만 봐줄 수 있어요. `[다른 파일 올리기]` `[이 장 건너뛰기]` | CAT/SymPy/DeepSeek 호출 없음 |
| unreadable | 흐림, 잘림, 빈 장 | 글자가 잘 안 보여요. 밝은 데서 다시 찍거나 문제 페이지만 올려 주세요. `[다시 촬영]` `[다른 파일]` | 동일 |

PDF는 **파일 전체가 아니라 문항 단위**. 수학 29 + 국어 1이면 29개는 살리고 1개만 막는다.
애매함은 문항마다 묻지 않고, 그 업로드/세션에 한 번만 묻는다.
막힌 입력은 Free/Pro 사용량에서 빼지 않는다.

채팅도 같다. “오늘 날씨”, “자소서 써줘”는 일반 GPT로 받아주지 않는다.
> 이 문제 말고는 수학만 도와줘요.

일부러 안 하는 것: 다른 과목 대충 해설, 긴 지원예정 팝업, 약관 위반처럼 꾸짖기, 비수학에 CAT 달기.

---

## 2. 같이 넣는 MVP 가드레일

수학 게이트만 있으면 우회·원가·가짜 학습이 남는다. 아래는 MVP에 같이 잠근다.

### G1. 해설지·정답지만 올린 경우
문항 지문 없이 답/풀이만 있으면 채점·CAT를 하지 않는다.
> 문제 지문이 안 보여요. 문제 쪽이 나오게 올려 주세요.

### G2. 빈 손풀이 / 너무 짧은 제출
흰 종이, 점 하나, 글자 거의 없음 → CAT 금지.
> 풀이가 거의 안 보여요. 한 줄만이라도 적힌 부분을 올려 주세요.

### G3. 파일 한도
- 파일 50MB 초과, 또는 한 번에 너무 많은 쪽(권장 상한 40쪽). 교과 전권 업로드 방지.
> 파일이 너무 커요. 50MB 이하로, 필요한 쪽만 나눠 올려 주세요.
페이지 초과는 앞 40쪽만 나누고 “나머지는 다음에 이어서 올릴 수 있어요”로 자른다. 전체 실패로 만들지 않는다.

### G4. 연타·중복 제출
같은 손풀이/같은 변형 버튼을 연속으로 누르면 첫 요청만 처리한다. 두 번째부터는 로딩만 유지. 토큰 이중 과금 없음.

### G5. 세션 밖 지시 / 프롬프트 무시
“이전 지시 무시”, 코드 작성, 번역 대행 등은 수학 튜터 범위를 벗어난다. not_math와 같은 거절. 모델이 역할에서 나가 일반 비서가 되지 않게 한다.

### G6. 정답만 반복 요구
`1 답만 빠르게 채점`은 허용(의도된 기능). 같은 문항에서 풀이 없이 “답만”을 반복하면 채점 결과는 주되, 전체 해설 덤프는 하지 않는다.
> 답은 확인했어요. 막힌 줄만 같이 볼까요?

### G7. 변형 문제 5게이트 (이미 ADR-008)
DeepSeek 출제 → SymPy → Gemini 블라인드. 실패분은 화면에 안 냄. 가드레일 목록에 포함만 하고 내용은 008을 따른다.

### G8. CAT 미확정은 기록하지 않음 (이미 ADR-021)
deferred / confidence < 0.6 / OCR 미확인 상태는 오답노트·숙달에 안 넣는다.

## 3. 호출 규칙 (원가)

| 상황 | Gemini 분류 | OCR 확인 | CAT | SymPy | DeepSeek |
|---|---|---|---|---|---|
| not_math / unreadable / 빈 손풀이 / 해설지만 | 1회 | 안 함 | 안 함 | 안 함 | 안 함 |
| maybe_math에서 아니오 | 1회 | 안 함 | 안 함 | 안 함 | 안 함 |
| math 통과 후 손풀이 | (분류와 공유 가능) | 함 | 함 | 필요 시 | 변형 요청 시 |
| 게이트에 막힘 | 사용량 0 | | | | |

분류 라벨은 가능하면 첫 비전 호출에 붙여서 왕복을 늘리지 않는다.

---

### G9. 물리·초등은 과목으로 받지 않는다
MVP 과목은 수능·내신·편입 수학뿐이다. 물리·화학 계산, 초등 연산은 **별도 과목 모드를 만들지 않는다.**
분류는 `maybe_math`로 두고 한 번만 묻는다.
- 예 → 그 세션만 수학 루프로 최선. 물리 법칙 해설기·초등 커리큘럼 엔진은 없다. SymPy가 되는 식만 검산한다.
- 아니오 → `not_math`와 같다. 본 루프 없음. 사용량 안 깎음.
초등이라고 등급을 깎거나 “이건 초등 문제예요”라고 하지 않는다. 모욕이 되고, 검정수·편입 기초 문항까지 막힌다.
물리·화학을 과목으로 푸는 라우터는 ADR-011 백로그다. 지금 게이트의 역할은 **과목 확장가 아니라 수학 루프 보호**다.
